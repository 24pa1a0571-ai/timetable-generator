# Timetable Generator & Viewer (React)

A responsive weekly timetable app built with React and Vite.

## Features
- View a weekly timetable from Monday to Friday
- Filter the timetable by day
- Add classes with subject, teacher, room, day and time
- Prevent two classes from using the same day/time slot
- Remove classes
- Generate a sample weekly schedule from the subjects already entered
- Responsive layout for desktop and mobile

## Run locally
1. Install Node.js (LTS).
2. Extract this project folder.
3. Open a terminal inside `timetable-generator`.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL printed in the terminal (usually `http://localhost:5173`).

## Note
This starter stores timetable data in React state, so changes reset when the page is refreshed. Add a backend or browser storage later if persistent data is required.
